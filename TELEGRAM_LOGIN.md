# Вход через Telegram (веб)

Сайт — **веб-версия**. Приложение Telegram **не нужно**.

## Как работает кнопка

1. Пользователь нажимает **«Войти через Telegram»**
2. Вводит свой `@username` (имя по желанию)
3. Сразу попадает в голосование

Никаких SMS, кодов и подтверждений в приложении.

## Render

Убедитесь, что:

```text
TELEGRAM_LITE_AUTH=true
```

(или переменную можно не задавать — по умолчанию `true`)

Бот (`TELEGRAM_BOT_TOKEN`) для этой кнопки **не обязателен**.
